# 2.5.0-beta.3 无线测试说明

这是 beta.2 的独立本地测试版本，未推送或发布；公开稳定版 2.4.3 与原 beta.2 目录保留。请先从托盘退出所有旧版定位工具，再运行完整解压的 beta.3；两个版本不要同时修改同一台手机。

## 第一次准备

1. 将 iPhone 用 USB 连接电脑，解锁并确认信任。保持手机和电脑连接同一个局域网，手机打开 Wi-Fi。
2. 启动 `iPhone虚拟定位.exe`，保持“USB 有线”，确认上方识别到手机。
3. 点击“首次无线准备（需 USB）”。这一步只完成配对和开关准备，尚未证明无线定位可用；操作结束后拔掉数据线。
4. 在“连接方式”选择“Wi-Fi 无线测试”，清空“手机 Wi-Fi IP”，点击“重新检测手机”。没有 Apple Network 设备时会自动查询约 4 秒的 mDNS 公告，校验已有配对后建立完整定位通道。若自动发现失败，仍可填写手机“设置 → 无线局域网 → 当前网络 ⓘ”显示的 IP，再点“重新检测手机”。自动和手动路径均须完成信任、设备身份、开发者模式、无线隧道、DVT 和定位服务通道验证，上方明确显示“Wi-Fi 已连接”后，才点击“修改定位”。
5. 手机上打开地图，点击当前位置核对。测试后点“恢复真实定位”，再在手机地图核对实际位置。恢复接口没有 GPS 回执，软件提示“待手机确认”是正常的。

之后测试版会记住所选连接方式和手机 IP。“一键修改.exe”也使用这些设置；若想回到 USB，在设置窗口将连接方式切回“USB 有线”。手机的 Wi-Fi IP 可能变化，届时请重新填写。

## 未发现无线手机时

- 手机与电脑应在同一个可互访的局域网；访客 Wi-Fi、AP 隔离、VPN 或防火墙可能阻止发现。
- 自动发现先查 Apple Mobile Device Service，无 Network 设备时直接浏览 `_remotepairing._tcp.local`。仅接受已有配对记录认证匹配的手机，多公告/多地址按手机去重，多台手机时拒绝自动选择。不会扫描网段、自动安装驱动或修改公司服务和网络配置。
- 如果手机仍插着 USB，软件会要求先拔线，以免将有线连接误判成无线成功。
- 如无线始终不可用，可选回 USB；原 2.4.3 仍可继续使用。

程序通过本机 Apple 设备服务或手机局域网 IP 与已配对手机通信，不开放局域网监听端口。首次无线准备会在手机上开启 Wi-Fi 设备连接。手动 IP 只保存在该测试版目录的 `wifi-host.txt`，不会放入公开 ZIP。不同 iOS、Windows 服务版本和网络环境下结果可能不同。

参考：[pymobiledevice3 iOS 17+ 连接说明](https://doronz88.github.io/pymobiledevice3/guides/ios17-tunnels/)；[Windows 安装说明](https://doronz88.github.io/pymobiledevice3/installation/)。

## 本机复用 beta.2 数据

先退出两版程序，在本机把原 beta.2 的 `state` 复制到新 beta.3 目录，可复用已有配对。需要原常用地点时再复制 `locations.xml`；需要保留原连接方式时可复制 `connection-mode.txt`。为测试自动发现，不复制 `wifi-host.txt`，或在界面清空 IP。原目录保持不动。

`state` 可能包含配对秘密，地点文件包含私人位置。上述复制仅限自己的本机测试，不要发送这些文件、提交 Git 或放入分发 ZIP。换电脑须在目标电脑重新 USB 准备。

复检会核对通道状态和新一次 lockdown 通信；失败撤销就绪状态。断线可能需要等下一次约 3 秒的检测及连接超时才能反映。此次不含地址查询或地址转坐标。测试包不含配对、地点、手机 IP 或预设连接方式。

本机验收记录见 `BETA3-VALIDATION.md`；构建环境说明见 `BETA3-BUILD.md`。
