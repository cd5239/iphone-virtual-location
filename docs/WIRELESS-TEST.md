# 2.5.0-beta.2 无线测试说明

这是从公开稳定版 2.4.3 分出的独立测试版。请先在原版托盘菜单选择“退出并结束定位”，再运行测试版；两个版本不要同时修改同一台手机。

## 第一次准备

1. 将 iPhone 用 USB 连接电脑，解锁并确认信任。保持手机和电脑连接同一个局域网，手机打开 Wi-Fi。
2. 启动 `iPhone虚拟定位.exe`，保持“USB 有线”，确认上方识别到手机。
3. 点击“首次无线准备（需 USB）”。这一步只完成配对和开关准备，尚未证明无线定位可用；操作结束后拔掉数据线。
4. 在“连接方式”选择“Wi-Fi 无线测试”，点击“重新检测手机”。若自动发现失败，在“手机 Wi-Fi IP”中填写手机“设置 → 无线局域网 → 当前网络 ⓘ”显示的 IP 地址，再点“重新检测手机”。程序会核对无线公告与已有配对，并实际建立定位隧道。上方明确显示“Wi-Fi 已连接”后，才点击“修改定位”。
5. 手机上打开地图，点击当前位置核对。测试后点“恢复真实定位”，再在手机地图核对实际位置。恢复接口没有 GPS 回执，软件提示“待手机确认”是正常的。

之后测试版会记住所选连接方式和手机 IP。“一键修改.exe”也使用这些设置；若想回到 USB，在设置窗口将连接方式切回“USB 有线”。手机的 Wi-Fi IP 可能变化，届时请重新填写。

## 未发现无线手机时

- 手机与电脑应在同一个可互访的局域网；访客 Wi-Fi、AP 隔离、VPN 或防火墙可能阻止发现。
- 自动发现依赖 Apple Mobile Device Service。pymobiledevice3 文档指出，Windows 的 Microsoft Store “Apple 设备”服务可能不发现 Wi-Fi 手机；经典 iTunes 安装包提供的服务通常支持。本测试版可用手动 IP 尝试单播发现，不会自动安装或修改驱动。
- 如果手机仍插着 USB，软件会要求先拔线，以免将有线连接误判成无线成功。
- 如无线始终不可用，可选回 USB；原 2.4.3 仍可继续使用。

程序通过本机 Apple 设备服务或手机局域网 IP 与已配对手机通信，不开放局域网监听端口。首次无线准备会在手机上开启 Wi-Fi 设备连接。手动 IP 只保存在该测试版目录的 `wifi-host.txt`，不会放入公开 ZIP。不同 iOS、Windows 服务版本和网络环境下结果可能不同。
