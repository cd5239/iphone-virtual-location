# USB 与 Wi-Fi 使用说明（2.5.1）

## 首次准备

1. 从托盘退出旧版定位工具，完整解压新版到新目录，保持 exe、engine 和 source 的目录结构。
2. 用 USB 连接 iPhone，解锁并信任电脑，开启开发者模式，点击“首次无线准备（需 USB）”。准备完成仅代表配对和开关就绪，尚未验证 Wi-Fi 定位通道。
3. 拔掉 USB，保持手机解锁，手机与电脑处于可互访的局域网。
4. 点击手机 Wi-Fi IP 右侧“检测”。如果原先是 USB 模式，会自动切到 Wi-Fi。IP 留空时自动发现；填写手机当前 IPv4 时使用单播发现。两条路径都校验已有配对和设备身份，打开完整定位服务通道后才报告可用。
5. 检测到手机后选择地点，再点击“修改定位”。地图实际位置仍须在手机核对。

## 重复检测

可直接再点击“检测”，不必切换连接方式。检测中会显示“检测中…”；正在修改、恢复或保持模拟定位会话时，检测按钮暂时禁用，避免切换连接中断定位。结束当前会话后再检测。输入 IP 时自动轮询暂缓，避免检测尚未输入完整的地址。

若需要保持当前连接方式重新检查，也可使用底部“重新检测手机”。

## 本机升级与隐私

退出旧版后，可在自己的本机将旧版 `state` 复制到 2.5.1 目录，复用已有配对；需要原地点时再复制 `locations.xml`，需要原连接方式时可复制 `connection-mode.txt`。为试验自动发现，清空 IP 或不复制 `wifi-host.txt`。保留旧目录，不覆盖原数据。

这些复制仅限自己的本机升级。state 可能包含配对凭据，地点文件包含私人位置，不能发到 GitHub、公开 ZIP 或他人。换电脑时应重新 USB 准备，不复用另一台电脑的配对文件。

自动发现不扫描网段，也不修改电脑的 Bonjour、Apple 服务、VPN、防火墙或公司网络策略。若多播无法通过，仍可尝试手机当前 IP；若公告与现有配对不匹配，需要重新 USB 准备。发现多台已配对手机时拒绝自动选择；验证 Wi-Fi 时目标仍连接 USB 会被拒绝。

“恢复真实定位”没有真实 GPS 回执。工具提示“待手机确认”后，应在手机地图中核对，不能只凭发送成功认定 GPS 已恢复。本版不含地址转坐标功能。
