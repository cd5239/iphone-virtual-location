# 换电脑使用

程序不依赖其他定位软件的安装目录、界面或进程，但仍需要 Apple 的设备驱动和服务。没有安装第三方手机助手的 Windows 电脑也可部署；尚未在全新电脑实测，不保证所有系统组合均可直接运行。

1. 建议使用 Windows 10/11 64 位，启用系统 .NET Framework 4.x（建议 4.8）。Python 已随连接组件打包，无需单独安装。
2. 安装 Apple 官方“Apple 设备”应用或合适的 iTunes/Apple Mobile Device Support，确保 Apple 驱动、设备服务正常，电脑可以通过 USB 识别手机。
3. 复制 iPhone虚拟定位.exe 与 一键修改.exe、整个 engine 和 source 文件夹，以及 locations.xml（如有）到新电脑同一文件夹中。原 location.xml 可一并保留用于旧配置迁移。
4. 不要复制 state 文件夹；它可能含本机配对凭据。新电脑会建立自己的缓存和配对。
5. 用数据线连接，解锁手机并手动确认“信任此电脑”，开启开发者模式。首次初始化开发者组件可能需要联网。
6. 打开主程序确认“手机已连接”，再选择常用地点并修改。手机定位最终显示仍需在地图里核对。

本机已验证设备为 iPhone 16 / iOS 26.6.2。其他版本尚未实测。不要仅复制一个 exe，它需要同目录的引擎和界面文件。

Apple 官方连接故障指引：https://support.apple.com/zh-cn/108643
