# 2.5.1 更新与验证

## 变更

- 手机 Wi-Fi IP 右侧新增“检测”按钮：点击后自动切换到 Wi-Fi，使用当前 IP 重新检测；IP 留空仍走已配对手机的自动发现。
- 在 Wi-Fi 模式可直接重复检测。已有检测未完成时串行处理新请求，采用最新输入的 IP；失焦保存 IP 不会额外抢发一次检测。正在输入 IP 时暂缓自动轮询。
- 正在修改、恢复或保持模拟定位会话时，检测按钮禁用，避免打断当前定位。
- “修改定位”采用独立 WPF 模板：常态蓝色、悬停加深、按下进一步加深，禁用时才为灰色，不再被系统主题的默认悬停色覆盖。
- 窗口、界面和版本文件统一为 2.5.1；保留 USB、认证后的 mDNS 自动发现、手动 IP、常用地点和恢复提示。
- 未增加地址搜索或地址转坐标。

## 验证范围

- 45 项 Python 回归测试覆盖原定位引擎、认证发现和异常路径。
- WPF 实际控件交互测试覆盖 USB 自动切 Wi-Fi、重复点击、串行请求、使用最新/空 IP，以及会话和操作中的保护；请求使用合成地址，只产生 probe，不发送定位指令。
- WPF 主按钮的常态、真实输入属性触发的悬停/按下、禁用颜色测试及截图检查；界面 96/144/192 DPI 离屏渲染。
- WPF 状态模型与合成地点存储自检。
- 本地 Windows ZIP 的 CRC、运行库和隐私检查；从最终 ZIP 解压验证两个入口和测试命令。

beta.3 的无线通道在此前已完成源码、打包引擎及 ZIP 解压后实机验证，用户于本次更新前反馈功能可用。本次主要修改界面，未改变认证和定位通道逻辑，也未发送实机定位修改/恢复命令。

旧版目录、旧标签和既有 GitHub Release 保留。源码、版本标签和项目简介同步到 `cd5239/iphone-virtual-location`。用户随后授权发布 [v2.5.1 Release](https://github.com/cd5239/iphone-virtual-location/releases/tag/v2.5.1)，提供已验证的 Windows ZIP、pymobiledevice3 对应源码及 SHA-256 清单。发布包与此前本地测试包相同，Windows ZIP 的 SHA-256 为 `34687f77f503fdf932db94800e291da6e415884e19a74f0797ac3ec34c2eaecb`。
