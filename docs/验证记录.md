# 2.5.0-beta.2 单播无线修复（2026-10-13）

- 用户实测 beta.1：USB 无线准备提示完成，拔线切无线后仍显示未发现手机。现场检查确认 USB 有线准备开关为开启、远程配对记录含 altIRK；拔线后 Windows Apple 设备列表没有 Network 设备，组播 Bonjour 也没有结果。
- 通过手机当前 Wi-Fi IP 查询 mDNS 单播可获得 RemotePairing 公告，并用公告 authTag 与本机配对记录匹配；旧 Python 3.12 环境的 `sslpsk-pmd3` 在当前 OpenSSL 环境下无法完成无线隧道 TLS-PSK。使用官方 CPython 3.13.16 原生 PSK 后，实机无线用户态 RSD 隧道成功建立。
- beta.2 增加可选手机 IP 输入与单播发现，仅在公告与已有配对记录匹配后连接；无线“已连接”须在 DVT 定位通道建立后才显示。无线准备反馈改为明确“待无线验证”。
- 后端 22 项测试、WPF 状态测试通过；96/144/192 DPI 离屏布局渲染成功。打包后引擎使用本机已配对 iPhone 经 Wi-Fi 返回 `connected/usable`；实际调用定位设置得到设备服务接受，随后两次发送停止模拟指令并正常退出。手机地图实际落点与恢复后的 GPS 仍待用户目视核验。
- beta.2 仍是本地测试版；2.4.3 稳定版及 beta.1 保留。公开 ZIP 不包含配对记录、地点 XML、连接方式或手动 IP 文件。
